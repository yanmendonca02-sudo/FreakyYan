# Yan Mendonça — Treino

App web (PWA) do treino FreakJota: Pull, Push, Legs Quad+, Full-upper e Legs Hams+.
Inclui cronômetro de descanso por exercício, cardio de 40 min, histórico em calendário e guia de RPE.

- HTML, CSS e JavaScript puros, sem build e sem dependências
- Progresso salvo no `localStorage` do aparelho
- Instalável no celular e funciona offline depois da primeira visita

## Rodar local

```bash
npx serve .
```

## Publicar

1. Suba o repositório no GitHub
2. Na Vercel: Add New → Project → importe o repositório
3. Framework Preset: Other. Deixe Build Command e Output Directory vazios
4. Deploy

## Instalar no celular

- iPhone: Safari → Compartilhar → Adicionar à Tela de Início
- Android: Chrome → menu → Instalar app
